# 📖 About

UtilityHub is a modern, responsive, all-in-one productivity website built entirely using **HTML**, **CSS**, and **Vanilla JavaScript**.

It combines multiple everyday tools into a single elegant interface, eliminating the need to visit different websites for simple tasks.

Designed with performance, accessibility, and user experience in mind, UtilityHub works seamlessly across desktop and mobile devices.

# 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/sreenand-cod/UtilityHub.git
```

Open the project:

```bash
cd UtilityHub
```

Launch:

```
Open index.html in your browser.
```

No installation required.

No dependencies.

No frameworks.

Works completely offline (except QR generation if an online API is used).

# 🔒 Privacy

UtilityHub stores your data locally in your browser.

No user accounts.

No tracking.

No analytics.

No personal data is sent to external servers.
